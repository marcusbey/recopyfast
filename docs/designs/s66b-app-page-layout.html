s66b · design reference

Every app page: one frame, one title, one left edge

The page frame is the dashboard layout (width, gutters, 56 px header, sidebar) plus one PageShell per page (title, rhythm, sections), per ADR 053. Dark theme, real token values, square containers and 2 px controls (ADR 050). The dashed yellow line in each frame is the page's left edge: every header, filter row and panel starts on it. s66b1 lands the frame and the titles; s66b2 flattens what is inside. Everything under /dashboard/sites is s66c's.

1 · The frame and PageShell (s66b1)

One owner per concern: the layout sets width and gutters; PageShell sets the title row and the vertical rhythm. Its direct children are the sections.

The emoji and the "PRO PLAN" copy stay (out of scope).
