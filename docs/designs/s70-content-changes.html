A · global page · 1280

Default filter “Changes” (pending + published). One panel per site, page bands inside, newest change first. The first row is expanded: compare, actions, history, technical details. Rows never show an element id or a selector.

  • No call to GET /api/sites; one GET /api/content/changes?state=changes returns sites, the first 50 rows and the three counts.
  • Northwind Docs is an edit grant: no “who” (history is admin-only by RLS), no Publish; Revert saves a draft.
  • ⋮ is visible at rest on every row; its menu is shown open on the Pricing “Button” row.

  • Save as draft → PUT /api/staging/content/<site> {elementId, content: original, language, variant}.
  • Revert and publish → the same PUT, then POST /api/staging/publish {siteId, elementIds:[elementId]}. Both existing routes (ADR 042 path, plan gate).
