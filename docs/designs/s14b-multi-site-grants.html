The per-device expiry line (grant-list) is new — listSiteEditors today returns none of this; it's a data requirement, not a design-system gap (see the .md's "Design system gaps"). "Expired" reuses StatusBadge tone="neutral", distinct label from "Removed" though both share the neutral tone. No action button next to an expired grant — there is no resend-by-agency endpoint; the editor's own next sign-in mints a fresh grant.
