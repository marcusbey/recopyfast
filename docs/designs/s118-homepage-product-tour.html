Hero correction · browser prototype

Give the dashed outline room.

The line clips the animated word’s outline. Keep the three-line headline and add 10px above and below each line. The outline needs 9px. Browser measurements at 320, 390, 768, 901, 1280 and 1440px showed no page overflow or clipped authored words.

Proposed fix: line padding provides space for the whole outline. Increasing inherited line-height alone also increases the outlined word’s box.

This spacing was tested by temporary browser styling. The repository CSS and production website have not been changed.
