# s118 product-tour asset provenance

Captured 2026-10-19 for the approved homepage product tour. All six images use
one controlled example, Bella Vista, and one opening-hours change:
`Tue–Sun · 5 to 10` → `Tue–Sun · 5 to 11`.

## Evidence boundary

These are fresh browser renders of the existing product components with
deterministic sample data. They verify that the current UI can present one
coherent setup-to-history walkthrough at the shipped asset dimensions. They do
not prove a complete authenticated backend journey: no production account,
Supabase row, registration, installation report, publish mutation, or history
row was created or read.

The local Supabase stack was unavailable for the capture. An isolated scratch
Next renderer imported the real components and styles. The Changes and history
requests were fulfilled in the browser with one fixed sample response. No
product auth, API, database, or source module was changed for the renderer.

The snippet in frames 1 and 2 is generated by the production
`buildEmbedScript()` helper, so it includes the actual `data-site-id`,

production project reference, session URL, API key, or credential. Sharp wrote
the WebP files without EXIF, XMP, or ICC metadata.
