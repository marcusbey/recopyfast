How we count a conversion

A conversion is a click on the tested element by a visitor, counted once per visitor, after that visitor has been assigned a variant. We compare it against assignments — how many visitors were bucketed into each variant — not raw page views, so a returning visitor's repeat clicks don't inflate the rate.

These three cards are the same screen at three different points in one test's lifecycle — shown side by side only for this review. In production, one card renders at a time, in the state the test is actually in.
