ReCopyFast on Some Hostile Platform

Not supported today — here's exactly why, and what to do instead.

ℹ

This platform strips injected scripts on save

Some Hostile Platform's page editor removes any <script> tag pasted into its content field when the page is republished, so the snippet cannot survive being installed here. This is a limitation of the platform's editor, not a bug in the tag — we tried, and recorded it rather than quietly leaving this stack off the list.

What to do instead: if this platform exposes a raw HTML/embed block or a custom-code injection setting outside the normal content editor, that path is not stripped — contact support and we'll verify it together. Otherwise, browse a stack that installs cleanly today.
